---
name: Portal Dashboard membership scope
description: Defines which Acuity packages the Portal Dashboard presents to members.
---

Portal Dashboard membership cards must mirror Mobile Home: display active Acuity certificates only when they are eligible for the configured Workout for 1 appointment type. Use the Acuity-returned product name and remaining value and support every eligible certificate; do not infer eligibility from product names, prices, visibility, family status, or discounts.

**Why:** The member dashboard is intended to help members choose a Workout for 1 credit consistently across Portal and Mobile while Acuity remains authoritative for both balance and eligibility.

**How to apply:** For future Portal membership UI, reuse the authenticated certificate source and the shared appointment-type eligibility helper. A separate all-package membership inventory would be a distinct product decision, not an incidental expansion of this dashboard section.
